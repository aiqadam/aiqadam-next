## AC9 — static/structural check, not a dynamic test case

**What it verifies:** "no code path sends the code/link to `issued_to_user`/
`grants_companion_of`/target/host — the bot only ever replies to the acting organizer's
own chat."

**Exact check TEST-RUNNER runs** (no judgment call — a plain repo-wide search, already
independently run and reported by SECURITY-REVIEWER in `step-02c-security-reviewer.json`,
re-run here as part of Step 4 rather than trusted from that report per
core-directives.md's "no speculation"):

```bash
git grep -nE "ctx\.reply|ctx\.api\.sendMessage|bot\.api\.sendMessage|answerCallbackQuery" apps/bot/src/handlers/inviteCodes.ts
git grep -n "grammy\|Context" apps/bot/src/domain/inviteCode.ts
```

**Expected result:**
1. The first command's every match is a bare `ctx.reply(...)`/`ctx.answerCallbackQuery(...)`
   call with **no explicit `chat_id`/recipient argument** (grammY's `ctx.reply` has no
   recipient parameter — it is bound to the incoming update's own chat by construction),
   confirmed by reading each matched line: none passes `targetUserId`, `hostUserId`,
   `issuedToUserId`, or `grantsCompanionOf` (or any variable derived from a `tgId` lookup
   on those) as an argument.
2. The second command returns **zero matches** — `domain/inviteCode.ts` imports no
   `grammy` symbol and references no `Context` type anywhere, so the domain layer cannot
   message anyone, structurally.

Record the actual command output (not a summary) in `test-reports/report-<date>-<run-id>.yaml`
under AC9, with `result: pass` only if both conditions above hold from the literal grep
output.

async function seedUser(tgId: number, opts: { role?: "member" | "organizer" | "owner"; chapterId?: string | null } = {}) {
  const user = await resolveOrCreateUser(db, { tgId: BigInt(tgId), tgUsername: `u${tgId}`, lang: "en" });
  if (opts.role !== undefined || opts.chapterId !== undefined) {
    await db
      .update(users)
      .set({
        ...(opts.role !== undefined ? { role: opts.role } : {}),
        ...(opts.chapterId !== undefined ? { chapterId: opts.chapterId } : {}),
      })
      .where(eq(users.id, user.id));
  }
  return user;
}

async function latestInviteCodeRow(eventId: string) {
  const rows = await db.select().from(inviteCodes).where(eq(inviteCodes.eventId, eventId)).orderBy(asc(inviteCodes.createdAt));
  const row = rows[rows.length - 1];
  if (row === undefined) throw new Error("latestInviteCodeRow: no row found for this event");
  return row;
}
